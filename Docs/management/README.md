# Management materials

Executive and programme-sponsor materials for **Mirage Suite**.

## Canonical visual deck

| Artifact | Use |
| --- | --- |
| [Mirage_Suite_Deck.pdf](./Mirage_Suite_Deck.pdf) | Present / share the 15-slide Executive Briefing |
| [Mirage_Suite_Deck.pptx](./Mirage_Suite_Deck.pptx) | Editable master (image-based slides) |
| [assets/deck/slides/](../assets/deck/slides/) | Optimized JPEGs for Docs embeds (regenerate via [extract script](../assets/deck/extract-deck-slides.sh)) |

Macro journey on every slide: **Discover → Decide → Deliver → Retire**.

## Readable companion

| Document | Use |
| --- | --- |
| [Executive briefing](./executive-briefing.md) | Slide-by-slide transcript, talk track, slide image embeds |
| [Visual catalog](./visual-catalog.md) | Region-by-region inventory of every visual element |
| [Slide map](./slide-map.md) | Crosswalk: slide → image → catalog → product/engineering Docs |
| [Engagement next steps](./engagement-next-steps.md) | Standalone Align → Assess → Plan → Execute one-pager |

Use the PDF/PPTX for live presentation. Use the markdown briefing + visual catalog when you need searchable text, speaker notes, or full visual parity without opening PowerPoint.

**Deck images vs product screenshots:** briefing artwork lives under `assets/deck/`; live UI captures live under `assets/screenshots/` only.

## Ownership

This folder owns: deck binaries, quantified outcome claims (always labelled *illustrative*), engagement next steps, visual catalog, and the executive narrative.

It does **not** own: API details, deployment topology, or local runbooks — see [engineering/architecture.md](../engineering/architecture.md).
